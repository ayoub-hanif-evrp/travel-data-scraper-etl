        Pipeline

        How the demonstration transforms source pages into delivery-ready outputs.

        1. Source HTML Configured English Wikivoyage destination pages only.
        2. Scrapy Extraction Structured listing fields extracted from semantic markup.
        3. Raw JSONL Source values preserved before destructive transforms.
        4. Cleaning Whitespace, URLs, phones, and coordinates normalized carefully.
        5. Validation Required fields and ranges checked; rejects retained with reasons.
        6. Deduplication Deterministic identity keys; first occurrence kept.
        7. CSV / JSONL / SQLite Analysis-ready structured exports with indexed SQLite storage.
        8. Quality Report Run metrics, completeness, and rejection summaries.
        9. Data Delivery Dashboard Static HTML/CSS/JavaScript view of the delivered dataset.

        Responsible crawling
